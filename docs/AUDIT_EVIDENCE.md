## Remaining proof boundary

No repository test can prove real Branch credentials/dashboard routing, Android `assetlinks.json`, iOS AASA/entitlements, signing identities, a store-mediated app-not-installed → install → first-launch handoff, Firebase DebugView/warehouse ingestion, global referral-code uniqueness, production authentication, authoritative account creation, fraud rules, or transactional rewards. Those checks must be completed with Mal-owned provider projects, signed builds, physical iOS/Android devices, Play internal testing/TestFlight, and a real backend.
